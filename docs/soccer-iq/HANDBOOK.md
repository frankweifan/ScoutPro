## 1. 项目定位与目标

### 1.1 为什么要做

现有 ScoutPro（U9-U10 评估系统）以**教练主观 1–5 分评分**为主，其中"接球前观察(sc)""决策速度(ds)""决策质量(dq)""观察能力(ob)""空间觉察(sa)""攻防转换(tr)"等条目都属于球商范畴，但缺少**可回看的视频证据**和**可量化的行为数据**。

球商分析系统要解决三件事：

| 问题 | 解决方式 |
|---|---|
| 球商"看不见、说不清" | 把球商拆成**可在视频中观察到的行为**，逐项定义、逐次计数 |
| 教练评分因人而异 | 统一定义 + 判定标准 + 校准片段库，让不同分析师得出一致结果 |
| 评价无法转化为训练 | 每个指标都对应训练处方，形成"比赛 → 数据 → 训练 → 比赛"闭环 |

### 1.2 产品目标

1. **针对指定球员**，从比赛视频中标注其球商相关行为，自动汇总统计。
2. 输出**球商雷达图 + 关键数据卡 + 视频片段集锦 + 训练建议**的个人报告。
3. 支持**纵向追踪**（同一球员多场趋势）；同年龄段基准由本系统自有数据逐步建立（目前没有公开的青少年分龄基准，见 8.1）。
4. 数据可回流到现有 ScoutPro 评估条目，作为主观评分的证据支撑。
5. 分阶段从"人工标注"走向"半自动 / AI 辅助"（见第 10 章）。

### 1.3 球商的工作定义

> **球商 = 在比赛中持续地「看到」→「想明白」→「选择」→「做到」→「调整」的能力。**

这个循环有两国的官方或学术依据：

- **日本**：JFA《Japan's Way》第 2 版要求"提高从认知到执行的速度"（認知から実行のスピードを高めたい），并要求培养"能自主判断、兼顾战术与个性"的球员 [J1]。JFA 学院今治把它细化为「認知→分析→判断→実行」（认知→分析→判断→执行），并指出前三步"在头脑中用语言完成"[J7]。
- **西班牙**：在巴塞罗那执教的坪井健太郎介绍的西班牙 PAD+E 框架是感知（Percepción）、分析（Análisis）、决策（Decisión）加执行（Ejecución），技术只是这个过程最后可见的部分 [JP11]。Seirul·lo 的结构化训练把"认知结构"定义为负责"感知—行动"过程的结构 [S2]。

本系统在此基础上加入"反馈 / 转换与心理"作为第五环：

```
 ┌───────────┐   ┌───────────┐   ┌───────────┐   ┌───────────┐   ┌────────────┐
 │ ① 感知     │──▶│ ② 分析     │──▶│ ③ 决策     │──▶│ ④ 执行     │──▶│ ⑤ 反馈/转换 │
 │ 扫描·朝向  │   │ 场区·人数  │   │ 提前·最优  │   │ 第一脚     │   │ 失误后反应  │
 │ 观察对象   │   │ 对手位置   │   │ 最快·选项  │   │ 跑动·沟通  │   │ 转换·心态   │
 └───────────┘   └───────────┘   └───────────┘   └───────────┘   └─────┬──────┘
       ▲                                                              │
       └──────────────────────────────────────────────────────────────┘
```

## 2. 方法论基础：日本、西班牙青训的球商关注点（附出处）

> 说明：仓库中仍未存放此前日本、西班牙青训课程的原始讲义。本章依据公开可查的资料编写，每条附出处。**请教练组把当时的课程笔记、训练视频补充到 `docs/soccer-iq/references/`**，以便和公开资料互相印证。

### 2.1 两国共同的核心方法：设计环境 + 少下指令

调研发现，两国培养球商的主要手段，**不是让球员执行口号式规则，而是教练设计比赛环境、并克制自己**：

| 共同方法 | 日本依据 | 西班牙依据 |
|---|---|---|
| 用人数少、有对手的小场比赛代替分解练习 | 8 人制：参与球的次数多，判断次数就多；要看的东西比 11 人制少，判断更明确 [J3]；4v4 / 5v5 / 8 人制 SSG 指南 [J2]；池上正："足球的最小单位是 2 对 1 或 2 对 2" [JP6] | Seirul·lo 以"优先模拟情境"（situaciones simuladoras preferenciales，SSP）为训练单位，"通过规则、空间和参与人数来引导"，"目的不是学会练习，而是学会比赛" [S2]；巴萨："The concept is not taught, the concept is played"（概念不靠讲解，在比赛中习得）[S4] |
| 用规则、服务者、场区改变决策难度 | 国家训练中心 U-12：服务者、线门、"同一区域不进 3 人"等约束 [J5]；U-14：按场区和人数状况给"挑战 / 安全"配权重 [J6] | Seirul·lo：用规则、空间、人数调控任务 [S2]；UCLM：用代表性任务"训练选择性注意"（entrenar la atención selectiva）[S12] |
| 教练退后，让球员自己决定 | 「待つ」（等待）、「答えを先に出さない」（不先给答案）、连续追问；"比赛是孩子的时间，教练只当主持人" [J4]；SSG 场地管理员"原则上只在旁守望" [J2] | 比利亚雷亚尔：理想球员是"自主的、懂比赛的（能分析不断变化的环境做决定）、有价值观的球员" [S10]；方法论负责人反对在持续指令下训练："比赛时球员独自踢球，自己做决定" [S19] |
| 不惩罚判断失误 | 致家长"即使失败，也绝不要责备" [J3]；"不是做不到，而是还没做到" [J1] | 不要惩罚冒险；只在赛前给指令、赛中不纠正的那一队创造力提升更多 [S9]；鼓励创造力、允许犯错的环境才能培养出自主型球员 [S10] |

**对本系统的影响**：第 4 章的"一定要做到"准则，与两国主流理念存在张力。v0.2 把准则改为**按年龄、场区、人数状况条件化的情境判断**（见第 4 章），并建议复盘时同时看"教练是否给了球员决策空间"。

|---|---|---|---|

| 相手を見て、動きながらのテクニック | 看着对手，在移动中发挥技术 | [J1] 一手·官方 | A 模块、D7 |

| ライン間で受ける / 3人目のサポート | 在线间接球、第三人支援、利用宽度 | [J1] 一手·官方 | C4、C6 |

| 待つ / たたみかける質問 | 等待，不先给答案；提问要连续追问几次 | [J4] 一手·官方 | 8.5 |
| 問いかけ（提问式指导） | 作为核心方法出自池上正（非 JFA 正式术语）：先区分技术失误和判断失误 | [JP1] 二手 | 8.5 |
| 答えは相手が教えてくれる | 岩政大树：答案由对手告诉你 | [JP12] 一手·本人 | A6、D5 |
| 審判の判定は受け入れる | 8 人制单裁判制的目的：哨响前一直踢、裁判错了也接受判罚、倒地马上起来 | [J3] 一手·官方 | F1、F4 |

### 2.3 西班牙青训关注点

| 关注点（原文） | 含义 | 出处（等级） | 本系统指标 |
|---|---|---|---|
| **Estructura cognitiva**（认知结构） | 负责"感知—行动"过程，高效捕捉、识别、处理比赛信息 | [S2] 一手·学术 | A 模块 |
| **Atención selectiva**（选择性注意） | 逐步教会青少年每种情境中哪些要素是关键 | [S12] 一手·学术 | A6 |
| 先有比赛表现，后有理论知识 | 青少年先获得决策与执行，再获得能说出来的战术知识；决策发展不是线性的 | [S12] 一手·学术 | 8.3（U10 不评 B4） |
| **Perfilarse**（侧身准备） | 巴萨情境游戏的重点之一；要了解队友传球前的身体朝向 | [S4] 一手·官方 | A1 |
| 用离球远的脚接球 | 让球从身前滚过，下一脚出球选项更多（Seirul·lo 观点转述） | [S18] 二手 | A1 |
| **Juego de posición**（位置游戏） | 在小空间里高速配合，**吸引压迫者，解放空位队友**；格式 8v8+3、4v4+3、3v2+2v1 | [S6] 一手·官方 | C 模块、D11 |
| 优势类型 | 数量、位置、质量优势，Seirul·lo 体系另有"社会情感优势" | [S3] 一手·官方 | B3 |
| **Fijar**（吸引 / 牵制） | 持球者吸引防守人后出球，属于"吸引以解放"，**不是身体假动作** | [S6] 一手·官方；UCLM 课程材料仅搜索摘要 | D11（新增） |
| **Desmarque**（摆脱跑位） | 摆脱直接防守者、获得时空优势、为持球者提供解决方案；分"衔接"和"传球"两阶段；跑位者要不断思考哪里、何时、如何、为何 | [S11] 一手·学术 | C 模块 |
| Acoplar / generar líneas de pase | 协调传球线路避免相互干扰、制造空间、创造传球线路 | [S11] 一手·学术 | C3、C7、D1 |
| 持球只占约 2% | "关注其余时间应是球员培养的基础" | [S11] 一手·学术 | C 模块权重 |
| **3P** | presión（压迫）、posesión（控球）、posición（位置）是巴萨方法论轴心 | [S5] 一手·官方 | F2、D9 |
| Conservaciones（控球游戏） | 不以进球为目标，以保持传球线路畅通为目标 | [S4] 一手·官方 | D9、F5 |
| Love the ball | 前青训主管：让孩子从小不怕持球 | [S18] 二手 | D1、F7 |
| 丢球后立即压迫 | 一线队做法：Kuper 说 5 秒内抢不回就退回，Sky Sports 说"六秒规则"；**两者矛盾，均无一手来源** | [S16] [S17] 二手 | F2（不设硬阈值） |
| 个人目标即可观察行为 | 比利亚雷亚尔：持球时分析情境以推进获得优势、给持球队友提供解决方案、多配合少单干、沟通更流畅 | [S10] 一手·官方兼学术 | B、D1、E |
| 引导发现 / 冻结—重建 | UCLM 理解式教学：自评、互评、引导发现、战术板、"congelar y reconstruir"、暂停辩论 | [S13] 一手·学术 | 9 章、8.5 |
| 情绪-意志结构 | 识别、调节、引导情绪与欲望 | [S2] 一手·学术 | F 模块 |

### 2.5 本手册不再采用的说法（无可靠出处）

v0.1 中以下说法在调研中**找不到可靠出处**，v0.2 已删除或改写：

| 说法 | 处理 |
|---|---|
| "日本教练要求接球前至少看两次" | 删除。JFA 一手文件没有「首を振る」的正式定义，也没有次数要求 |
| "5 秒反抢" | 改为"丢球后立即反应"，记录连续反应时间，窗口可配置（见 F2、R6） |
| Pausa（停顿）/ 间（ま） | 删除，改用 JFA 三区和人数状况原则（见 F5） |
| Menos toques（少触球）是西班牙原则 | 删除西班牙归属，改引 JFA 对前锋"以少的触球"射门和传球 [J1] |
| Pase y va 规则化教法；"传球后不动对方得球权" | 删除，改用有出处的替代规则（见第 9 章） |

## 3. 球商指标体系（核心）

### 3.0 指标结构约定

每个指标统一包含以下字段（附录 A.1 为完整字典）：

| 字段 | 说明 |
|---|---|
| **ID** | 模块字母 + 序号，如 `A2` |
| **名称 / 定义** | 一句话说清"是什么" |
| **判定标准** | 视频中"看到什么才算"，必须可观察 |
| **记录方式** | `计数` / `是否(0/1)` / `等级` / `时长(秒)` |
| **计算指标** | 输出给报告的数值 |
| **依据** | 出处编号（附录 A.6）；无外部出处的标【教练组】 |
| **自动化等级** | `L1` 纯人工；`L2` 半自动（系统给候选，人工确认）；`L3` 可自动 |

**通用口径：**

- **频率类**统一折算为 **每 10 分钟在场时间（/10min）**；扫描例外，按**次/秒**计（与科研协议一致 [R1]）。
- **比率类**分母必须是"**机会次数**"。机会是否成立由分析师判定（见 5.4 节）。
- **【探索】指标**：只在报告中展示和追踪趋势，不计入维度分，待本系统双人编码信度达标（12.1 节）后再决定是否转正。
- **同时报告原始计数**，不只报告比率（GPAI 类工具的使用建议，见调研报告）。

**压力等级（P）**：

| 等级 | 定义（U12 及以下按小场比例缩放）【教练组】 |
|---|---|
| P0 无压 | 最近防守人距离 > 5 m，且未朝球员移动 |
| P1 中压 | 2 – 5 m，或防守人正在逼近 |
| P2 高压 | < 2 m，或已发生身体接触 / 被包夹 |

> 科研发现最近对手在 0–1 米内时扫描最少，紧逼会降低扫描 [R1] [R2]，所以 A 模块必须分压力统计。

**人数状况（N）**：球所在局部区域的攻守人数对比，分**劣势 / 均势 / 优势**，与场区一起用于判断"挑战还是安全"（依据 JFA U-14 训练菜单 [J6]）。

**分析师提示**：
- 全景机位往往看不清头部转动，A 模块强烈建议使用**目标球员跟拍机位**（见第 6 章）。
- 成人英超参照值为 **0.44 次/秒、每次控球 3.0 次**，中前卫最多、前锋最少 [R1]。**这不是青少年目标**；目前没有公开的青少年分龄基准。
- 扫描对传球成功的效应很小（作者称"small, but positive"）[R1]，所以 A2 在报告中定位为**过程指标、看成长趋势**，不作为单场能力判断。

### 3.2 模块 B：分析与决策（Decision Making）

| ID | 指标 | 定义与判定标准 | 记录 | 计算指标 | 依据 | 自动化 |
|---|---|---|---|---|---|---|
| **B1** | 提前决策 | 接球第一脚即为下一个动作服务（直接传、转身、趟向空档），第一触与下一动作之间无停顿、无再扫描 | 每次接球 0/1 | 提前决策率 | JFA"认知到执行的速度" [J1]；风间"一次进攻约 1 秒" [JP8] | L2 |

| **B4** | 是否最优 | 按 **场区 × 人数状况** 判断该"挑战"还是"安全"，再对选项排序；选了排名第 1 为最优 | 2 最优 / 1 次优 / 0 非优 | 最优选择率；决策质量均分 | JFA 三区与人数权重 [J1] [J6]；GPAI 合适/不合适编码 [R7] | L1 |
| **B5** | 是否最快 | 同等价值选项中，是否选了能最快执行、最早让球离开压力的方案 | 0/1 | 最快选择率 | 【教练组】 | L1 |
| **B6** | 决策综合分 | 提前 + 最优 + 最快 = 3 分 | 0–3 | 均分 | 计算 | 计算 |

**"最优"判定规则：**

1. 定格于球员**接球前最后一刻**或**触球瞬间**；
2. 先看场区和人数状况：**进攻三区、人数优势 → 偏挑战**（越过防线、进入口袋、射门）；**防守三区、人数劣势 → 偏安全**（保持球权、转移、回传）（JFA U-14 训练菜单 [J6]）；
3. 执行难度要与该球员年龄段相符；
4. 有争议的片段进入每周**校准会**由主教练裁定，加入校准片段库。

> 编码难度提醒：西班牙一套观察工具中，"接球时决策"是信度最低的一项（0.537）[R10]。B1、B4 必须配套书面判定规则和校准片段，双人编码一致性达标后才计入评分。

## 4. 球员行为准则及执行率

以下是教练组提出的行为原则，系统单独列为"准则执行率"，在报告中以红黄绿灯显示。

> **v0.2 调整**：这些原则大多是【教练组】自定，而两国主流做法是"设计环境、让球员判断"（2.1 节）。为避免变成机械规则，v0.2 把执行判定改为**按年龄、场区、人数状况条件化**，并为每条标出依据状态。绿灯阈值均为【待确认】。

| ID | 准则 | 机会（分母） | 执行（分子）判定 | 依据状态 | 绿灯阈值 |
|---|---|---|---|---|---|
| **R1** | **传球后一定前插 / 移动** | 本人每次完成传球（射门、解围、定位球除外） | 传球后 2 秒内：**前插**（执行，优先）或**拉开 / 换位重新形成传球线路**（执行，标注类型）；原地不动或慢走 = 未执行 | "传球后马上考虑下一次怎么接" [JP14] 二手；"一定前插"为【教练组】，与巴萨"保持位置、占据空间" [S6] 有张力 | ≥ 70% |
| **R2** | **反击时第一脚一定稳** | 反击中本人第一次触球 | D10 成功 | 两国说法方向不同（见 D10），口径【待确认】 | ≥ 80% |
| **R3a** | **给队友留够决策空间** | 本人每段持续无球跑动 | 未挤占持球人线路和空间（C7） | 有依据 [S11] [J5] | 挤占 ≤ 2 次/场 |
| **R3b** | **不往一个方向跑**（反击前插除外） | 同上 | 方向有变化（C5） | 【教练组】 | 单向跑 ≤ 2 次/场 |
| **R4** | **无球时二人 / 三人换位、交叉跑** | 本队控球且本人在进攻区域的阶段（每 30 秒一个机会窗口）【待确认】 | 出现一次 C6 | 方向有依据 [J1]，频率无依据 | ≥ 1 次 / 5 min |
| **R5** | **不随意丢失球权，不乱解围**，用假动作和欺骗替代解围 | 本人在后场 / 中场受压持球 | 未出现无目标解围与低级失误。**U10 及以下全场适用；U11 起防守三区高压下的有目标解围计为执行** | U10 以下有依据 [JP5]；高龄段作为通则与 JFA 三区原则不符 [J6] | 技术化解率 ≥ 60% |
| **R6** | **丢球后立即反应、不抱怨** | 本队每次丢球 | 在可配置窗口内参与反抢或回位（F2）且无抱怨（F4） | "立即夺回"有依据 [J1]；秒数无一手依据 | ≥ 80% |

**执行率 = 执行次数 ÷ 机会次数**，报告中附上"未执行"片段，方便教练回看。复盘时建议同时检查**该场训练和比赛中教练是否给了球员决策空间**（场边指令过多会压制球员自己的判断 [J4] [S9]）。

## 5. 事件标注规范

### 5.1 数据模型：一条事件（Event）

| 字段 | 示例 | 说明 |
|---|---|---|
| `event_id` | 自动 | |
| `match_id` / `video_id` | | 关联比赛与视频 |
| `player_id` | | 目标球员（也可标注队友 / 对手作为关联人） |
| `t_start` / `t_end` | 00:12:31.4 | 视频时间戳，精确到 0.1 秒 |
| `period` | 1 / 2 | 上下半场 |
| `phase` | 组织 / 进攻 / 攻转守 / 守转攻 / 防守 / 定位球 | 比赛阶段 |
| `type` | `scan` / `receive` / `pass` / `fake_run` … | 事件类型，对应指标 ID |
| `subtype` | `behind` / `front` / `2p` / `3p` … | 子类型 |
| `value` | 0–4 / 秒数 | 等级或时长 |
| `outcome` | 成功 / 失败 / 中性 | |
| `pressure` | P0 / P1 / P2 | 见 3.0 |
| `numbers` | 劣势 / 均势 / 优势 | 人数状况，见 3.0 |
| `zone` | `M-LHS`（中场·左半空间） | 场区，见 5.2 |
| `possession_id` | | 同一次球权串联 |
| `is_opportunity` | true | 是否为某条准则的"机会" |
| `annotator` / `confidence` | 张三 / 0.8 | 标注人与把握度 |
| `note` | | 自由备注 |
| `clip_flag` | 好球 / 待改进 | 是否加入报告集锦 |

### 5.2 场区划分

纵向三区 × 横向五道 = 15 区：

```
            左边路   左半空间   中路    右半空间   右边路
 前场 A   │  A-LW  │  A-LHS  │  A-C  │  A-RHS  │  A-RW  │
 中场 M   │  M-LW  │  M-LHS  │  M-C  │  M-RHS  │  M-RW  │
 后场 D   │  D-LW  │  D-LHS  │  D-C  │  D-RHS  │  D-RW  │
```

纵向三区同时就是 JFA 三区原则里的进攻三区 / 中间区 / 防守三区 [J1]，用于 B4、D3、D9、R5 的条件判断。"口袋" = 对方中场线与后卫线之间、`M/A-LHS`、`M/A-C`、`M/A-RHS` 中无人盯防的位置，标注时加 `pocket=true`。

### 5.3 两遍标注法

1. **第一遍：比赛骨架**（初级分析师或自动化完成）
   - 标记球权变化、本人每次接球 / 传球 / 射门 / 丢球的时间点，形成 `possession_id` 序列。
2. **第二遍：球商行为**（资深分析师）
   - 以本人每次接球为锚点，**向前回看 10 秒**标注 A 模块（扫描、侧身）；
   - 在接球瞬间定格，标注 B 模块（场区、人数、选项、最优、最快）；
   - 正常速度回看无球阶段标注 C、E 模块；
   - 在每次失误 / 丢球 / 转换点标注 F 模块与准则 R。

建议回放速度：A 模块 0.5×；B 模块逐帧定格；C/E/F 模块 1×。

### 5.4 "机会"判定原则

- 只在**球员确实有条件做**的时候计为机会（如传球后被对手立即撞倒，不计 R1 机会）。
- 不确定时标 `confidence < 0.6`，统计时可选择剔除，质检时重点复核。

## 7. 分析工作流程（SOP）

```
赛前准备 → 视频采集 → 导入与切分 → 第一遍标注 → 第二遍标注 → 质检 → 计算与报告 → 反馈会 → 训练处方 → 下场追踪
```

| 步骤 | 负责人 | 输入 | 产出 | 参考用时（单人单场） |
|---|---|---|---|---|
| 1. 赛前准备 | 教练 + 分析师 | 球员个人发展计划（IDP） | 本场**重点观察指标**（3–5 项）、目标球员位置 | 10 min |
| 2. 视频采集 | 摄像 | 第 6 章规范 | 全景 + 跟拍视频 | 比赛时长 |
| 3. 导入与切分 | 分析师 / 系统 | 原始视频 | 去除中场休息、死球长时段；多机位同步 | 15 min |
| 4. 第一遍标注 | 初级分析师 / 系统 | 视频 | 球权骨架 | 30–45 min |
| 5. 第二遍标注 | 资深分析师 | 骨架 + 视频 | 全量球商事件 | 90–150 min |
| 6. 质检 | 第二名分析师 | 抽样 20% 事件 | 一致性报告，修正 | 20 min |
| 7. 计算与报告 | 系统 | 事件 | 指标、雷达、集锦、自动建议 | 自动 |
| 8. 教练复核 | 主教练 | 报告草稿 | 调整结论，填写训练建议 | 15 min |
| 9. 反馈会 | 教练 + 球员（+ 家长） | 报告 + 片段 | 球员自我认知与目标 | 15–20 min |
| 10. 训练处方 | 教练 | 弱项指标 | 下一周期训练重点（第 9 章） | — |

**MVP 阶段建议**：先只做**重点观察指标**，不做全量，单场工作量控制在 1 小时左右。

> 个人发展计划（IDP）在 JFA《Japan's Way》中是育成体系的组成部分 [J1]；比利亚雷亚尔的做法是教练先给自己设目标，再给球员设个人目标，年底出一份保密的个人年度报告交给下一任教练组 [S10]。可作为本系统报告和 IDP 衔接的参考。

## 8. 评分模型、年龄段基准与报告

### 8.1 从原始数据到分数

```
原始事件 → 指标值（次/秒、次/10min、比率、均分） → 同年龄段百分位 → 1–5 分 → 维度分 → 球商总分
```

- **百分位到 1–5 分**：<20% = 1，20–40% = 2，40–60% = 3，60–80% = 4，≥80% = 5（与现有 ScoutPro 1–5 分体系一致）。
- **冷启动**：目前**没有公开的青少年分龄基准**（扫描也只有成人英超均值 [R1]）。在本系统积累 ≥30 名同龄球员样本前，**只展示个人趋势和原始数值，不出百分位分数**；教练组如需临时阈值，标【教练组】。
- **样本量保护**：某指标机会次数 < 5 时，报告显示"样本不足"，不参与评分。
- **【探索】指标**不计入维度分。

### 8.2 球商六维雷达

| 维度 | 计分指标（不含【探索】） | 默认权重【待确认】 |
|---|---|---|
| 观察 | A1、A2、A6、A7（A2 作为过程指标，看趋势为主） | 15% |
| 决策 | B1–B6 | 20% |
| 无球 | C1、C3、C4、C6、C7 + R1/R3/R4 | 20% |
| 持球 | D1–D3、D7–D11 + R2/R5 | 20% |
| 沟通 | E3 | 10% |
| 转换与心理 | F1–F5、F7 + R6 | 15% |

> v0.2 把观察维度从 20% 降到 15%、无球从 15% 升到 20%：扫描对表现的效应很小 [R1]，而持球只占比赛约 2% 的时间 [S11]。

### 8.3 年龄段侧重与期望

年龄阶段参照 JFA《Japan's Way》第 2 版的三段（始動 5–8 / 成長 9–12 / 挑戦 13–17）[J1] 与西班牙教练资格法规的"启蒙（10 岁以下）/ 技术基础习得（11–13 岁）"[S1]：

| 年龄段 | 重点指标 | 说明 |
|---|---|---|
| **U8 – U10** | A2 观察习惯、D1 敢要球、D7 第一脚（不苛求精度）、F1/F7 失误后反应与勇气、R5 不乱解围（全场） | 养成阶段，只看"有没有做"；**B4 最优决策不计入评分**（青少年先有比赛表现、后有理论知识 [S12]；U10 比 U12 更倾向带球是年龄特征 [R22]）；川崎前锋 U-12 也以带球和颠球为主，不以"停与踢"为主 [JP10] |
| **U11 – U13** | A1 侧身、A6 观察对象、B1 提前决策、C4 口袋、C6 换位、C7 留空间、D9 不乱解围（按场区）、D11 吸引并释放 | 引入场区、人数与位置概念；JFA 9–12 岁诊断项包括沟通能力 [J1] |
| **U14 – U16** | B3–B5 选项 / 最优 / 最快、C1 跑盲侧、F3 转换速率、E3 沟通有效性、D8 处理效率 | JFA 13–17 岁诊断项包括"俯瞰全局、分析情境的战术理解力" [J1]；U19 比 U17 扫描多 [R2] |

### 8.4 个人报告结构

1. **封面**：球员信息、比赛信息、出场时间、本场重点观察指标
2. **一句话总结**：本场最大亮点 + 最需改进的 1 项
3. **关键数据卡**（6 张）：如"扫描 0.31 次/秒（近 5 场 ↑）""传后移动执行率 55%"
4. **球商六维雷达**（本场 vs 近 5 场均值；基准建立后再加同龄对比）
5. **准则执行灯**：R1–R6 红黄绿
6. **视频集锦**：好球 3 段 + 待改进 3 段，每段配一个**引导问题**
7. **趋势图**：重点指标近 N 场变化（含【探索】指标）
8. **训练建议**：2–3 个具体训练方法（第 9 章自动推荐 + 教练修改）
9. **与 ScoutPro 评估条目映射**（附录 A.3）

### 8.5 反馈原则（附出处）

| 原则 | 做法 | 出处 |
|---|---|---|
| 等待，不先给答案 | 播放片段时先问，不先讲结论；留出孩子思考的时间 | [J4] |
| 连续追问 | 一个问题不要只问一次，顺着回答再问几次 | [J4] |
| 先分清技术失误还是判断失误 | 技术失误练技术，判断失误练判断；提问示例："看右边了吗？左边呢？后面呢？" | [JP1] |
| 肯定挑战 | 勇敢挑战失败也说"好的挑战"，把注意力放到下一步；赛后私下问"怎么样？" | [JP13] |
| 不责备、"还没做到" | 不用"做不到"，用"还没做到"；绝不因失败责备 | [J1] [J3] |
| 赛中少纠正 | 赛前给指令、赛中不纠正，有利于创造力 | [S9] |

| 用视频做"冻结—重建" | 让球员在战术板上重建当时的局面，再讨论其他选择 | [S13] |
| 一次只给 1–2 个改进点；不在队内公开排名 | U10 以下用游戏化徽章代替分数；家长版报告只呈现成长趋势 | 【教练组】 |

## 12. 质量控制、伦理与隐私

### 12.1 质量控制

- **标注一致性**：每月抽取 2 场由两名分析师独立标注。关键指标（A2、B1、B4、R1、F1）的一致性目标为 Cohen's κ ≥ 0.7 或 ICC ≥ 0.75；不达标的指标重新培训或修订定义。参照：Jordet 协议的扫描计数 ICC 为 0.979 [R1]；"接球时决策"在西班牙一套工具中信度只有 0.537 [R10]，B1、B4 需要格外重视。
- **【探索】指标转正**：本系统自有数据的双人编码一致性达标后，由技术总监决定是否计入评分。
- **校准片段库**：每个指标至少 5 个"标准正例" + 5 个"标准反例"，新分析师上岗前须通过测试（正确率 ≥ 85%）。
- **定义变更管理**：指标定义修改须记录版本号，报告中注明使用的指标版本，避免跨版本比较失真。

### 12.2 伦理与隐私（未成年人）

- 拍摄、录音、佩戴传感器与数据使用须取得**监护人书面同意**，明确用途仅限球员发展。
- 视频与数据按机构隔离存储，开启 RLS；分享链接设有效期。
- 不向第三方出售或公开个人数据；对外宣传使用须单独授权。
- 不给孩子贴"球商低"的标签；报告措辞以成长为导向。
- 数据保存期限【待确认】，到期可申请删除。

### 附录 A.5 待确认事项清单

1. 第 4 章各准则的绿灯阈值、R1 执行判定（是否接受"拉开 / 换位"）、R4 机会窗口长度。
2. D10 / R2 "反击第一脚稳"的口径：直奔球门，还是先交给最近的安全队友。
3. F1、F2、R6 的观察窗口（默认 3 秒、5 秒均为教练组设定）。
4. 第 8.2 节六维权重。
5. A1 侧身角度阈值；压力等级的距离阈值。
6. 是否每场都配备跟拍机位；是否试用头戴传感器（决定 A 模块能否全量开展）。
7. 音频采集方案与监护人同意流程。
8. 首批试点球员与年龄段（建议从现有 U9-U10 用户中选 6–10 名），并以试点数据建立双人编码信度和首批基准。
