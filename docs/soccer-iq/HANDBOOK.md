## 1. 项目定位与目标

### 1.1 为什么要做

现有 ScoutPro（U9-U10 评估系统）以**教练主观 1–5 分评分**为主，其中"接球前观察(sc)""决策速度(ds)""决策质量(dq)""观察能力(ob)""空间觉察(sa)""攻防转换(tr)"等条目都属于球商范畴，但缺少**可回看的视频证据**和**可量化的行为数据**。

球商分析系统要解决三件事：

| 问题 | 解决方式 |
|---|---|
| 球商"看不见、说不清" | 把球商拆成**可在视频中观察到的行为**，逐项定义、逐次计数 |
| 教练评分因人而异 | 统一定义 + 判定标准 + 校准片段库，让不同分析师得出一致结果 |
| 评价无法转化为训练 | 每个指标都对应训练处方，形成"比赛 → 数据 → 训练 → 比赛"闭环 |

### 1.2 产品目标

1. **针对指定球员**，从比赛视频中标注其球商相关行为，自动汇总统计。
2. 输出**球商雷达图 + 关键数据卡 + 视频片段集锦 + 训练建议**的个人报告。
3. 支持**纵向追踪**（同一球员多场趋势）与**同年龄段基准对比**。
4. 数据可回流到现有 ScoutPro 评估条目，作为主观评分的证据支撑。
5. 分阶段从"人工标注"走向"半自动 / AI 辅助"（见第 10 章）。

### 1.3 球商的工作定义

> **球商 = 在比赛中持续地「看到」→「想到」→「做到」→「调整」的能力。**

对应四层循环（与日本 JFA 的「認知・判断・実行」、西班牙的 *percepción – decisión – ejecución* 一致），本系统额外加入"心理与转换"作为第四环：

```
   ┌──────────────┐     ┌──────────────┐     ┌──────────────┐     ┌──────────────┐
   │ ① 感知/观察   │ ──▶ │ ② 判断/决策   │ ──▶ │ ③ 执行        │ ──▶ │ ④ 反馈/转换   │
   │ 侧身·扫描     │     │ 提前·最优·最快 │     │ 第一脚·欺骗    │     │ 失误后反应    │
   │ 宽度·深度     │     │ 选项数量       │     │ 无球跑动·沟通  │     │ 转换速率·心态 │
   └──────────────┘     └──────────────┘     └──────────────┘     └──────┬───────┘
          ▲                                                              │
          └──────────────────────────────────────────────────────────────┘
```

## 2. 方法论基础：日本、西班牙青训的球商关注点

> 说明：仓库中暂未存放此前日本、西班牙青训课程的原始讲义。以下内容按两国青训通行理念整理，并与本次需求逐条对应。**请教练组把当时的课程笔记、训练视频补充到 `docs/soccer-iq/references/`**，以便后续校准。

### 2.1 日本青训（JFA 及代表性青训体系）关注点

| 日本理念 | 含义 | 本系统对应指标 |
|---|---|---|
| **首振り（转头观察）** | 接球前反复转头，掌握身后和两侧信息；日本教练常要求"接球前至少看两次" | A2 扫描次数、A4 身后观察 |
| **認知・判断・実行** | 每个动作都先看、再判断、后执行；评价时三者分开打分 | 指标体系的 A/B/D 三大模块 |
| **止める・蹴る（停球与踢球）** | 第一脚把球"停在下一个动作的位置"，高度重视触球精度 | D6 第一脚触球质量 |
| **3人目の動き（第三人跑动）** | 二人传递时，第三人提前启动接应 | C6 换位/交叉、C3 创造空档 |
| **サポートの角度と距離** | 接应的角度与距离，让持球人至少有两个选项 | D1 主动接应、B3 可选决策数量 |
| **ボールを大切に（珍惜球权）** | 低龄阶段不鼓励大脚解围，用技术和配合化解压力 | D8 不乱解围、准则 R5 |
| **切り替え（攻防转换）** | 丢球瞬间立即反抢或回位 | F3 转换速率、准则 R6 |
| **主体性（自主性）与问いかけ（提问式指导）** | 让孩子自己思考，教练用问题引导而非命令 | 第 8.5 节反馈原则 |
| **コーチング（场上沟通）** | 队员之间互相提醒"後ろ！""ターン！" | E1 呼应、E2 场上说话 |

### 2.2 西班牙青训（拉玛西亚等体系、位置足球）关注点

| 西班牙理念 | 含义 | 本系统对应指标 |
|---|---|---|
| **Perfil（侧身/开放身体）** | 接球时身体半开，能同时看到来球方向和前场 | A1 侧身站位 |
| **Percepción（感知先于技术）** | 先找信息，再处理球；Rondo 训练核心 | A 模块整体 |
| **Juego de posición（位置游戏）** | 占据正确位置以制造数量 / 位置 / 质量优势 | C3 创造空档、B3 选项数量 |
| **Entre líneas（线间 / 口袋）** | 在对方两条防线之间、半空间接球 | A6 观察口袋、C 模块 |
| **Tercer hombre（第三人）** | 通过第三人绕开压迫 | C6 换位/交叉 |
| **Pase y va / Pared（传后即走 / 撞墙配合）** | 传球后立刻移动，不站桩 | 准则 R1 传球后一定前插 |
| **Fijar（吸引并固定防守人）** | 持球人用身体朝向、眼神、节奏把防守人固定住再出球 | D4 欺骗 |
| **Pausa（耐心 / 停顿）** | 不急于出球，等待最佳时机 | F5 耐心与稳定 |
| **Menos toques（少触球）** | 能一脚不两脚，提高处理效率 | D7 触球次数与效率 |
| **Tras pérdida（丢球后 5 秒反抢）** | 丢球后立即就近反抢 | F2 丢球后反应、准则 R6 |
| **Mentalidad（心态）** | 不抱怨裁判和队友，专注下一球 | F4 不抱怨、F6 注意力 |

### 2.3 需求 × 理念 × 系统模块 对照总表

| 本次需求原话 | 日本 | 西班牙 | 系统模块 |
|---|---|---|---|

| 假动作、眼神和身体朝向欺骗、更轻松地欺骗和突破 | 駆け引き | Fijar / Engaño | D 欺骗 |

## 3. 球商指标体系（核心）

### 3.0 指标结构约定

每个指标统一包含以下字段（附录 A 为完整字典）：

| 字段 | 说明 |
|---|---|
| **ID** | 模块字母 + 序号，如 `A2` |
| **名称 / 定义** | 一句话说清"是什么" |
| **判定标准** | 视频中"看到什么才算"，必须可观察 |
| **记录方式** | `计数` / `是否(0/1)` / `等级(0-3)` / `时长(秒)` |
| **计算指标** | 输出给报告的数值，如"每 10 分钟次数""成功率""执行率" |
| **自动化等级** | `L1` 纯人工；`L2` 半自动（系统给候选，人工确认）；`L3` 可自动 |

**两个通用口径（全手册适用）：**

- **频率类**统一折算为 **每 10 分钟在场时间（/10min）**，消除出场时间差异。
- **比率类**分母必须是"**机会次数**"，而非总时长。例如"传球后前插执行率 = 传球后前插次数 ÷ 有前插空间的传球次数"。机会是否成立由分析师判定（见 5.4 节）。

**压力等级（P）**——多处指标需要分压力统计：

| 等级 | 定义（U12 及以下按小场比例缩放） |
|---|---|
| P0 无压 | 最近防守人距离 > 5 m，且未朝球员移动 |
| P1 中压 | 2 – 5 m，或防守人正在逼近 |
| P2 高压 | < 2 m，或已发生身体接触 / 被包夹 |

### 3.1 模块 A：感知与观察（Perception & Scanning）

| ID | 指标 | 定义与判定标准 | 记录 | 计算指标 | 自动化 |
|---|---|---|---|---|---|
| **A1** | 侧身站位（开放身体姿态） | 接球瞬间，双肩连线与来球方向夹角约 30°–90°，能同时看到来球与前场/目标方向即为"开放"；正对来球背对前场为"关闭" | 每次接球 0/1 | **开放接球率** = 开放接球 ÷ 接球总数（分压力） | L2（姿态估计） |
| **A2** | 扫描次数 | 头部明显转动、视线**离开球**去看其他区域，一次转头 = 1 次扫描（往返算 1 次）。统计两个窗口：**接球前 5 秒**、**无球全时段** | 计数 | 接球前扫描次数均值；**扫描频率**（次/10s 无球时间）；**接球前扫描率**（接球前 ≥1 次扫描的接球占比） | L2 / L3（头部朝向） |
| **A3** | 全面扫描（覆盖象限） | 将球员周围分为 4 个象限：前、左、右、**身后**。接球前 5 秒内看过几个象限 | 0–4 | 平均覆盖象限数；"全面扫描率"（≥3 象限） | L2 |
| **A4** | 接球前身后观察 | 接球前 5 秒内至少一次看向身后（头部转过 >90°） | 每次接球 0/1 | **身后观察率** | L2 |
| **A5** | 观察宽度与深度 | **宽度**：一次扫描覆盖的左右范围（窄=只看一侧，宽=两侧边路都看）；**深度**：视线到达的最远层次（本方后场 / 同线 / 对方中场线 / 对方后卫线 / 门前） | 宽度 1–3；深度 1–5 | 平均宽度分、平均深度分 | L1（需结合分析师判断视线目标） |
| **A6** | 观察对象 | 扫描时看到了什么：①防守人位置 ②队友位置 ③空档位置 ④口袋（线间/半空间）。以"随后的动作是否利用了该信息"反推 | 每次扫描多选 | 四类对象的覆盖率；"信息利用率"（扫描后动作用上了扫描信息的比例） | L1 |
| **A7** | 最后扫描至触球时间 | 最后一次扫描结束到接球触球的时间差，越短说明信息越新 | 秒 | 均值（参考：优秀球员 ≤1.0 s）【待确认基准】 | L2 |

**分析师提示**：全景机位往往看不清头部转动，A1–A7 强烈建议使用**目标球员跟拍机位**（见第 6 章）。

### 3.2 模块 B：判断与决策（Decision Making）

| ID | 指标 | 定义与判定标准 | 记录 | 计算指标 | 自动化 |
|---|---|---|---|---|---|
| **B1** | 提前决策（接球前已决定） | 接球第一脚即为下一个动作服务（直接传、转身、趟向空档），而不是停住再看再决定。判定：第一触与下一动作之间**无停顿、无再扫描** | 每次接球 0/1 | **提前决策率** | L2 |
| **B2** | 随时决策 / 决策时延 | 从接球触球到出球（传/射/突破启动）的时间 | 秒 | 平均决策时延（分压力） | L3（球与球员跟踪） |
| **B3** | 可选决策数量 | 在接球瞬间定格画面，分析师列出所有**合理可行**的选项（传给某队友 / 带球推进 / 突破 / 射门 / 回传 / 保护球） | 场上可选数 N；球员可能识别数 n | 平均可选数；**选项识别率** n/N（结合 A 模块扫描证据判定） | L1 → L3（传球可行性模型） |
| **B4** | 是否最优 | 对选项按"**推进价值 × 成功概率 − 风险**"排序，球员选择排名第 1 为最优，第 2 为次优，其他为非优 | 等级：2 最优 / 1 次优 / 0 非优 | **最优选择率**；决策质量均分 | L1（需教练共识） |
| **B5** | 是否最快 | 在同等价值选项中，是否选了能最快执行、最早让球离开压力的方案；或在可以一脚出球时是否一脚出球 | 0/1 | **最快选择率** | L1 |
| **B6** | 决策综合分 | B1×B4×B5 的组合：提前 + 最优 + 最快 = 3 分 | 0–3 | 决策综合均分 | 计算 |

**"最优"判定规则（统一口径，防止各自为政）：**

1. 定格于球员**接球前最后一刻**或**触球瞬间**；
2. 优先级：**进攻推进**（越过防线 / 进入口袋 / 制造射门） > **保持球权并转移** > **安全回传**；
3. 同时考虑执行难度是否与该球员年龄段相符；
4. 有争议的片段进入每周**校准会**由主教练裁定，并加入校准片段库。

### 3.3 模块 C：无球跑动（Off-the-Ball Movement）

| ID | 指标 | 定义与判定标准 | 记录 | 计算指标 | 自动化 |
|---|---|---|---|---|---|
| **C1** | 跑盲侧次数 | 从防守人**视线背后**（盲区）启动跑动，防守人需转头才能看到 | 计数 | 次/10min；跑盲侧后获得传球的比例 | L2 |
| **C2** | 假跑次数（身前 / 身后） | 先向一个方向启动带走防守人，再变向接应或进入空档。**身前假跑**：先回撤再前插；**身后假跑**：先前插再回撤要脚下 | 计数，分身前/身后 | 次/10min；假跑成功率（甩开防守 ≥2 m 或拉出空档） | L2 |
| **C3** | 创造空档次数 | 通过跑动把防守人带离某区域，**使队友**在该区域获得空间或接球（自己不一定接球） | 计数 | 次/10min；"为队友创造的接球次数" | L1 |
| **C4** | 进入口袋/线间次数 | 在对方两条防线之间、或半空间无人盯防区域停留并示意接球 | 计数 | 次/10min；口袋接球次数 | L2 |
| **C5** | 跑动方向多样性 | 统计无球跑动方向（前插 / 回撤 / 横向 / 斜线）分布；**单向跑**（连续 3 次以上同方向直线前冲，反击前插除外）记为一次 | 计数 + 方向分布 | 方向分布熵；单向跑次数 | L3（跟踪数据） |
| **C6** | 二人 / 三人换位、交叉跑 | 与 1–2 名队友互换位置或交叉跑动，导致防守人盯人混乱或交接 | 计数，分 2 人/3 人 | 次/10min；有效换位率（造成空档或接球） | L2 |
| **C7** | 给队友留决策空间 | 跑动时**不挤占**持球队友的出球线路和带球空间（与持球人保持合理距离与角度）；挤占记负 | 正/负计数 | 净值 | L1 |

### 3.4 模块 D：持球、接应与触球（On-the-Ball）

| ID | 指标 | 定义与判定标准 | 记录 | 计算指标 | 自动化 |
|---|---|---|---|---|---|
| **D1** | 主动接应要球次数 | 主动移动到持球队友的可传球线路上，并用手势 / 声音 / 跑动明确示意要球 | 计数 | 次/10min；接应后实际接到球比例 | L2 |
| **D2** | 持球次数（球权） | 一次连续控制球 = 1 次持球（从第一触到球离开或被抢） | 计数 | 次/10min；平均持球时长 | L3 |
| **D3** | 被抢 / 丢失球权次数 | 区分：**被抢断**（对手直接抢走）、**失误丢球**（传球/控球失误）、**合理丢球**（射门、高风险推进未果） | 计数，分类 | 每 10 次持球丢球数；分压力的保有率 | L2 |
| **D4** | 假动作次数 | 有意图的身体假动作（踩单车、扣假射、虚晃等） | 计数 | 次/10min；**假动作成功率**（防守人重心被移动或晃开） | L1 |
| **D5** | 眼神 / 身体朝向欺骗 | 看向 / 身体朝向一个方向，实际传、带向另一个方向，并使防守人判断错误（西班牙所称 *fijar* / *engaño*） | 计数 | 次/10min；欺骗成功率 | L1 |
| **D6** | 欺骗后突破 / 摆脱 | 假动作或欺骗之后成功越过防守人或获得出球空间，且**动作代价小**（无需大幅加速、身体对抗少），即"更轻松地突破" | 计数 + 轻松度 1–3 | 突破成功率；平均轻松度 | L1 |
| **D7** | 第一脚触球质量 | 四个子项各 0/1，合计 0–4：①**方向**（触向空档 / 远离防守人 / 朝下一动作方向）②**高度**（球不弹起，或有意识地处理高度）③**力量**（球停在一步之内或推到可加速的位置）④**衔接**（第一触后能立即进行下一触或出球，无需调整步伐） | 0–4 | 第一脚均分（分压力）；第一脚失误率 | L1 / L2 |
| **D8** | 触球次数与处理效率 | 每次持球触球数；**处理效率** = 有效结果（成功传出 / 推进 / 射门）÷ 触球数 | 计数 | 平均每次持球触球数；一脚 / 两脚出球占比；处理效率 | L3 |
| **D9** | 不乱解围 | 在本方后场受压时，记录处理方式：**无目标解围** / **有目标长传** / **用假动作、欺骗、传球摆脱** | 分类计数 | **技术化解率** = 技术化解 ÷（技术化解 + 无目标解围） | L1 |
| **D10** | 反击第一脚稳定性 | 由守转攻后本人第一触是否稳定（未失误、方向向前或向空档） | 每次 0/1 | 反击第一脚成功率 | L2 |

### 3.5 模块 E：沟通（Communication）

| ID | 指标 | 定义与判定标准 | 记录 | 计算指标 | 自动化 |
|---|---|---|---|---|---|
| **E1** | 呼应次数 | 与持球队友的**信息交流**：要球（"这里！"）、提示（"身后有人！""转身！""时间够！"） | 计数，按类型 | 次/10min；提示类占比 | L2（音频） |
| **E2** | 场上说话次数 | 所有有效场上语言 + 手势，含组织（"压上""盯人"）与鼓励 | 计数，按类型 | 次/10min | L2（音频 VAD + 人工分类） |
| **E3** | 沟通有效性 | 沟通后队友动作是否随之改变（转身、回传、出球） | 0/1 | 有效沟通率 | L1 |

### 3.6 模块 F：转换与心理（Transition & Mentality）

| ID | 指标 | 定义与判定标准 | 记录 | 计算指标 | 自动化 |
|---|---|---|---|---|---|
| **F1** | 失误后反应 | 本人失误后 3 秒内的第一个行为：**积极**（立即反抢、回位、继续要球）/ **中性**（停顿后参与）/ **消极**（抱头、停下、抱怨、低头走） | 分类 | 积极反应率；平均"恢复时间"（失误到下一个积极动作，秒） | L1 |
| **F2** | 丢球后反应（5 秒反抢） | 本队丢球后，本人是否在 5 秒内向球压迫或进入防守位置 | 0/1 + 反应时间 | 反抢参与率；平均反应时间 | L2 |
| **F3** | 转换速率 | **攻转守**：球权转换到本人开始回追/压迫的时间；**守转攻**：获得球权到本人开始前插/拉开接应的时间 | 秒 | 两类转换平均反应时间 | L3（跟踪速度变化） |
| **F4** | 不抱怨 | 对裁判、队友、自己的抱怨性语言或肢体动作（摊手、指责） | 计数 | 次/场（目标 0） | L1 |
| **F5** | 耐心与稳定 | 有利时机未出现时选择**保持球权**（回传、转移）而非强行冒险；高压下持球不失误 | 计数 + P2 下保有率 | 耐心选择次数；高压保有率 | L1 |
| **F6** | 注意力 | **走神片段**：比赛进行中背对比赛、站立不动、未跟随球移动超过 5 秒 | 计数 + 时长 | 走神次数；专注时间占比 | L2（跟踪 + 朝向） |
| **F7** | 失误后的勇气 | 失误后**下一次主动要球**的时间间隔；以及失误后是否仍敢在压力下持球 | 秒 / 0-1 | 平均间隔；"失误后继续拿球率" | L2 |

## 4. 球员行为准则（"一定要做到"）及执行率

以下是教练组明确提出的**硬性行为原则**，系统单独列为"准则执行率"，在报告中以红黄绿灯显示。

| ID | 准则 | 机会（分母）定义 | 执行（分子）判定 | 绿灯阈值【待确认】 |
|---|---|---|---|---|
| **R1** | **传球后一定前插 / 移动** | 本人每次完成传球（除射门、解围、角球等定位球） | 传球后 2 秒内启动前插或换位接应；原地不动 / 慢走 = 未执行 | ≥ 70% |
| **R2** | **反击时第一脚一定稳** | 反击中本人第一次触球 | D10 成功 | ≥ 80% |
| **R3** | **不往一个方向跑**（反击前插除外），给队友留够决策空间 | 本人每段持续无球跑动 | 方向有变化，且未挤占持球人线路（C5/C7） | 单向跑 ≤ 2 次/场 |
| **R4** | **无球时二人 / 三人换位、交叉跑** | 本队控球且本人在进攻区域的阶段（每 30 秒为一个机会窗口）【待确认窗口长度】 | 出现一次 C6 | ≥ 1 次 / 5 min |
| **R5** | **不随意丢失球权，不乱解围**，用假动作和欺骗替代解围 | 本人在后场 / 中场受压持球 | 未出现无目标解围与低级失误（D3 失误丢球、D9 无目标解围） | 技术化解率 ≥ 60% |
| **R6** | **丢球后立即反应、不抱怨** | 本队每次丢球 | F2 = 1 且无 F4 | ≥ 80% |

**执行率 = 执行次数 ÷ 机会次数**，同时在报告中附上"未执行"片段，方便教练回看。

## 5. 事件标注规范

### 5.1 数据模型：一条事件（Event）

| 字段 | 示例 | 说明 |
|---|---|---|
| `event_id` | 自动 | |
| `match_id` / `video_id` | | 关联比赛与视频 |
| `player_id` | | 目标球员（也可标注队友/对手作为关联人） |
| `t_start` / `t_end` | 00:12:31.4 | 视频时间戳，精确到 0.1 秒 |
| `period` | 1 / 2 | 上下半场 |
| `phase` | 组织 / 进攻 / 攻转守 / 守转攻 / 防守 / 定位球 | 比赛阶段 |
| `type` | `scan` / `receive` / `pass` / `fake_run` … | 事件类型，对应指标 ID |
| `subtype` | `behind` / `front` / `2p` / `3p` … | 子类型 |
| `value` | 0–4 / 秒数 | 等级或时长 |
| `outcome` | 成功 / 失败 / 中性 | |
| `pressure` | P0 / P1 / P2 | 见 3.0 |
| `zone` | `M-LHS`（中场·左半空间） | 场区，见 5.2 |
| `possession_id` | | 同一次球权串联 |
| `is_opportunity` | true | 是否为某条准则的"机会" |
| `annotator` / `confidence` | 张三 / 0.8 | 标注人与把握度 |
| `note` | | 自由备注 |
| `clip_flag` | 好球 / 待改进 | 是否加入报告集锦 |

### 5.2 场区划分

纵向三区 × 横向五道 = 15 区：

```
            左边路   左半空间   中路    右半空间   右边路
 前场 A3  │  A-LW  │  A-LHS  │  A-C  │  A-RHS  │  A-RW  │
 中场 M   │  M-LW  │  M-LHS  │  M-C  │  M-RHS  │  M-RW  │
 后场 D1  │  D-LW  │  D-LHS  │  D-C  │  D-RHS  │  D-RW  │
```

"口袋"= 对方中场线与后卫线之间的 `M/A-LHS`、`M/A-C`、`M/A-RHS` 区域中**无人盯防**的位置，标注时加 `pocket=true`。

### 5.3 两遍标注法

1. **第一遍：比赛骨架**（可由初级分析师或自动化完成）
   - 标记球权变化、本人每次接球 / 传球 / 射门 / 丢球的时间点，形成 `possession_id` 序列。
2. **第二遍：球商行为**（资深分析师）
   - 以本人每次接球为锚点，向前回看 5 秒标注 A 模块（扫描、侧身、身后）；
   - 在接球瞬间定格，标注 B 模块（选项数、最优、最快）；
   - 正常速度回看无球阶段标注 C、E 模块；
   - 在每次失误 / 丢球 / 转换点标注 F 模块与准则 R。

建议回放速度：A 模块 0.5×；B 模块逐帧定格；C/E/F 模块 1×。

### 5.4 "机会"判定原则

- 只在**球员确实有条件做**的时候计为机会（如传球后被对手立即撞倒，不计 R1 机会）。
- 不确定时标 `confidence < 0.6`，统计时可选择剔除，质检时重点复核。

## 6. 视频采集规范

| 项目 | 要求 | 说明 |
|---|---|---|
| **主机位（全景）** | 中线延长线，高度 ≥ 4 m（支架 / 看台），覆盖全场 | 用于 B/C/F 模块、跟踪数据 |
| **跟拍机位（推荐）** | 一名摄像专门跟拍目标球员上半身 + 周围 10 m | **扫描、侧身、眼神欺骗、身后观察必须靠它** |
| 分辨率 / 帧率 | ≥ 1080p，≥ 25 fps；AI 分析建议 50 fps | 帧率影响扫描识别 |
| 稳定性 | 三脚架 / 云台，避免频繁变焦 | 自动化跟踪对抖动敏感 |
| 音频 | 跟拍机外接指向麦，或球员佩戴轻量麦克风（需监护人同意） | E 模块沟通类指标 |
| 赛前登记 | 双方球衣颜色、目标球员号码、首发名单、场地尺寸、赛制（5/7/8/11 人制） | 用于场区缩放和号码识别 |
| 文件命名 | `日期_赛事_对手_机位_半场.mp4`，如 `20261017_联赛_对手名_PAN_H1.mp4` | |
| 同步 | 开球时拍手 / 鸣哨作为多机位同步点 | |

## 7. 分析工作流程（SOP）

```
赛前准备 → 视频采集 → 导入与切分 → 第一遍标注 → 第二遍标注 → 质检 → 计算与报告 → 反馈会 → 训练处方 → 下场追踪
```

| 步骤 | 负责人 | 输入 | 产出 | 参考用时（单人单场） |
|---|---|---|---|---|
| 1. 赛前准备 | 教练 + 分析师 | 球员个人发展计划（IDP） | 本场**重点观察指标**（3–5 项）、目标球员位置 | 10 min |
| 2. 视频采集 | 摄像 | 第 6 章规范 | 全景 + 跟拍视频 | 比赛时长 |
| 3. 导入与切分 | 分析师 / 系统 | 原始视频 | 去除中场休息、死球长时段；多机位同步 | 15 min |
| 4. 第一遍标注 | 初级分析师 / 系统 | 视频 | 球权骨架 | 30–45 min |
| 5. 第二遍标注 | 资深分析师 | 骨架 + 视频 | 全量球商事件 | 90–150 min |
| 6. 质检 | 第二名分析师 | 抽样 20% 事件 | 一致性报告，修正 | 20 min |
| 7. 计算与报告 | 系统 | 事件 | 指标、雷达、集锦、自动建议 | 自动 |
| 8. 教练复核 | 主教练 | 报告草稿 | 调整结论，填写训练建议 | 15 min |
| 9. 反馈会 | 教练 + 球员（+ 家长） | 报告 + 片段 | 球员自我认知与目标 | 15–20 min |
| 10. 训练处方 | 教练 | 弱项指标 | 下一周期训练重点（第 9 章） | — |

**MVP 阶段建议**：先只做**重点观察指标**，不做全量，以控制单场工作量在 1 小时左右。

## 8. 评分模型、年龄段基准与报告

### 8.1 从原始数据到分数

```
原始事件 → 指标值（次/10min、比率、均分） → 同年龄段百分位 → 1–5 分 → 维度分 → 球商总分
```

- **百分位到 1–5 分**：<20% = 1，20–40% = 2，40–60% = 3，60–80% = 4，≥80% = 5（与现有 ScoutPro 1–5 分体系一致）。
- **基准库建立前**（冷启动）：先使用教练组设定的**绝对阈值**（附录 A 中的参考值），积累 ≥30 名同龄球员样本后切换为百分位。
- **样本量保护**：某指标机会次数 < 5 时，报告显示"样本不足"，不参与评分。

### 8.2 球商六维雷达

| 维度 | 构成指标 | 默认权重【待确认】 |
|---|---|---|
| 观察 | A1–A7 | 20% |
| 决策 | B1–B6 | 20% |
| 无球 | C1–C7 + R1/R3/R4 | 15% |
| 持球 | D1–D10 + R2/R5 | 20% |
| 沟通 | E1–E3 | 10% |
| 转换与心理 | F1–F7 + R6 | 15% |

### 8.3 年龄段侧重与期望

| 年龄段 | 重点指标 | 说明 |
|---|---|---|
| **U8 – U10** | A2 扫描习惯、A4 身后观察、D1 敢要球、D7 第一脚、R1 传后跑、F1/F7 失误后反应与勇气 | 养成习惯阶段，**只看"有没有做"，不苛求结果**；B4 最优决策不计入评分 |
| **U11 – U13** | A1 侧身、A6 观察口袋、B1 提前决策、C2 假跑、C4 口袋、C6 换位、D5 欺骗、D9 不乱解围 | 开始引入位置与空间概念 |
| **U14 – U16** | B3–B5 选项 / 最优 / 最快、C1 跑盲侧、F3 转换速率、E 沟通与领导、D8 处理效率 | 接近成人比赛要求，强调速度与质量 |

### 8.4 个人报告结构

1. **封面**：球员信息、比赛信息、出场时间、本场重点观察指标
2. **一句话总结**：本场最大亮点 + 最需改进的 1 项
3. **关键数据卡**（6 张）：如"接球前扫描率 68%（↑12%）""传后跑执行率 55%"
4. **球商六维雷达**（本场 vs 近 5 场均值 vs 同龄基准）
5. **准则执行灯**：R1–R6 红黄绿
6. **视频集锦**：好球 3 段 + 待改进 3 段，每段配一个**引导问题**
7. **趋势图**：重点指标近 N 场变化
8. **训练建议**：2–3 个具体训练方法（第 9 章自动推荐 + 教练修改）
9. **与 ScoutPro 评估条目映射**（附录 A.3）

### 8.5 反馈原则（借鉴日本「問いかけ」与西班牙引导式教学）

- **先肯定、后改进**，比例约 2:1；
- **用提问代替结论**：播放片段时问"接球前你看到了谁？""还有别的选择吗？"；
- **一次只给 1–2 个改进点**；
- 不在队内公开排名；对 U10 以下以**游戏化徽章**（如"扫描小达人"）替代分数；
- 家长版报告只呈现成长趋势与鼓励性描述，弱化横向比较。

### 10.2 与现有 ScoutPro 的集成

- 沿用现有技术栈：单页 HTML + Supabase（Auth、Postgres、RLS），PDF 用 jsPDF，图表用 Chart.js。
- 视频存储：Supabase Storage 或对象存储（OSS / S3），数据库只存元数据与片段时间码。
- `players` 表的 `age_group` 目前仅允许 `U9`/`U10`，需扩展到 U8–U16。
- 新增数据表草案（后续实现时细化）：

```sql
-- 比赛
CREATE TABLE matches (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  match_date DATE NOT NULL,
  competition TEXT DEFAULT '',
  opponent TEXT DEFAULT '',
  format TEXT CHECK (format IN ('5v5','7v7','8v8','11v11')),
  pitch_length_m NUMERIC, pitch_width_m NUMERIC,
  created_by UUID REFERENCES profiles(id),
  created_at TIMESTAMPTZ DEFAULT NOW()

-- 视频（多机位）
CREATE TABLE match_videos (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  match_id UUID REFERENCES matches(id) ON DELETE CASCADE,

-- 出场记录（计算 /10min 用）
CREATE TABLE match_appearances (
  match_id UUID REFERENCES matches(id) ON DELETE CASCADE,

  PRIMARY KEY (match_id, player_id)
);

-- 球商事件

  zone TEXT, pocket BOOLEAN DEFAULT FALSE,

  metric_id TEXT, value NUMERIC, opportunities INT, score_1_5 NUMERIC(3,2),
  PRIMARY KEY (match_id, player_id, metric_id)
);
```

### 10.3 自动化路线图

| 阶段 | 能力 | 涉及技术 | 可自动化的指标 |
|---|---|---|---|
| **V1 人工 + 计算**（MVP） | 快捷键标注，系统自动统计与出报告 | 前端标注工具 | 所有指标（人工） |
| **V2 半自动** | 球员与球检测、多目标跟踪、球衣号码识别、场地坐标映射（单应性变换）；自动切分球权，自动给出接球/传球候选时间点 | 目标检测 + 多目标跟踪、OCR、场地关键点 | D2、D8、B2、C5、F3、压力等级、场区 |
| **V3 AI 辅助** | 人体姿态估计 → 头部转向、肩线朝向；音频语音活动检测；传球可行性 / 空间控制模型计算可选项 | 姿态估计、音频 VAD、Pitch Control 类模型 | A1–A4、A7、E2、B3、F6 |
| 始终人工 | 涉及意图与质量判断的指标 | 教练判断 | A5/A6、B4/B5、C3/C7、D4–D6、D9、F1、F4、F5 |

**原则**：自动化结果默认 `source='auto'`，需人工确认后才计入正式报告；每个自动化指标上线前须与人工标注对比，**准确率 ≥ 90%** 方可启用。

## 12. 质量控制、伦理与隐私

### 12.1 质量控制

- **标注一致性**：每月抽取 2 场由两名分析师独立标注，关键指标（A2、A4、B1、B4、R1、F1）一致性 Cohen's κ ≥ 0.7；不达标的指标重新培训 / 修订定义。
- **校准片段库**：每个指标至少 5 个"标准正例"+ 5 个"标准反例"，新分析师上岗前须通过测试（正确率 ≥ 85%）。
- **定义变更管理**：指标定义修改须记录版本号，报告中注明使用的指标版本，避免跨版本比较失真。

### 12.2 伦理与隐私（未成年人）

- 拍摄与数据使用须取得**监护人书面同意**，明确用途仅限球员发展。
- 视频与数据按机构隔离存储，开启 RLS；分享链接设有效期。
- 不向第三方出售或公开个人数据；对外宣传使用须单独授权。
- 不给孩子贴"球商低"的标签；报告措辞以成长为导向。
- 数据保存期限【待确认】，到期可申请删除。
