# U10 教练员守则

> 适用对象：本队 U10 主教练、助理教练、守门员教练、领队及所有与球员接触的工作人员
> 版本：v1.0（2026-11）｜赛季开始前签署，并在家长会上向家长公开
> 来源编号（如 [JFA-SG]）可点击，完整列表见文末"参考来源"

**总原则**

> 把每名球员的福祉、安全和乐趣放在一切之上，包括胜利。——英格兰足总教练守则 [FA-COACH]

> 比赛是孩子的时间，教练专心当好组织者。——JFA U-8/U-10 手册 [JFA-KIDS]

---

## 一、底线：绝不可以做（零容忍）

| # | 守则 | 依据 |
|---|---|---|
| 1 | **不用暴力指导，也不让别人这样做；无论出于什么目的，都不容许暴力。** 严格可以，暴力不行 | JFA 2013 暴力根绝宣誓书三条 [JFA-SG]；JFA 2019 安全保护宣言"零容忍" [JFA-SAFE] |
| 2 | **不辱骂、不羞辱、不贬低孩子**，不在孩子面前说脏话 | [FCB-CC] [FIFA-GS] [JFA-SAFE] |
| 3 | **不偏袒、不排斥。** 不因能力、家庭背景或个人好恶区别对待孩子 | [FCB-CC] [FIFA-GS] |
| 4 | **不在封闭空间与一名孩子独处。** 单独谈话要在其他人看得见的地方 | [FCB-CC] [FCF] [FIFA-GS] |
| 5 | **不通过私人渠道与孩子联系。** 只用球队官方渠道和家长沟通 | [FCB-CC] [FCF] |
| 6 | **不未经家长书面同意拍摄或发布孩子的照片和视频**；比赛分析视频只用于教学，不公开 | [FCB-CC] [JL-SG] |
| 7 | **不对任何暴力、骚扰、欺凌视而不见。** 发现问题立即报告儿童保护负责人，"不行动不是一个选项" | [FIFA-GS] [JFA-SG] |
| 8 | **不以"我就是这样被带出来的"为理由延续体罚和吼骂。** 切断负面循环 | [JFA-SG]（原则 12） |

## 二、执教理念：一定要做到

| # | 守则 | 依据 |
|---|---|---|
| 1 | **以孩子为中心。** 热爱运动比学会运动更重要；训练要有趣、安全、循序渐进 | UEFA 儿童教练十条 [UEFA-10] |
| 2 | **用比赛教比赛。** 多用小场、有对手、多触球的比赛，用规则、场地和人数引导孩子自己发现 | [JFA-SSG] [DFB] |
| 3 | **不教成人化套路，不固定位置。** 7–9 岁球权频繁易手是正常的起点；每名球员轮换前、中、后场和门将 | [FA-TR] [KNVB] [DFB] |
| 4 | **比赛中以守望为主。** 赛前讲清楚 1–2 个重点，赛中少喊、少纠正，留给中场和赛后 | [JFA-SSG]（"基本只在旁守望"） [JFA-KIDS] [BIHUB-CR] |
| 5 | **公平出场。** 每名到场球员每场至少踢一半时间；人多时分队参赛 | JFA："让全员上场是本来的宗旨" [JFA-8] [JFA-PH]；"至少一半"为【本队规定】 |
| 6 | **用竞赛促进发展。** 鼓励孩子为赢而拼，但不以输赢评价孩子，不排队内名次 | [UEFA-10] [JFA-SSG] |
| 7 | **关注全人发展。** 技术、战术、身体、心理、社交一起看 | [UEFA-10] [JFA-JW] |
| 8 | **守护健康。** 高温、雷雨等天气按规定调整或暂停训练；保证饮水和休息；有急救准备 | [JFA-SAFE]（第 3、5 条） [FIFA-GS] |

## 三、反馈方式：孩子对教练的请求

JFA 的球员手册里写着孩子们对教练的请求 [JFA-PH]：

- "请具体告诉我哪里好、怎样能更好。"
- "请用容易懂的话和示范告诉我。"
- "一次可能学不会，请别马上发火，看着我。"
- "请别说'你怎么做不到''你怎么不懂'。"
- "比赛中被吼，我就只想着那个声音，别的什么都想不了。"

据此，本队教练这样反馈：

| 做法 | 说明 | 依据 |
|---|---|---|
| **等待，不先给答案** | 先问"你看到了什么？""还有别的选择吗？"，连续追问几次 | [JFA-KIDS] |
| **分清技术失误和判断失误** | 技术失误练技术，判断失误练判断 | [IKEGAMI-1] |
| **肯定挑战** | 勇敢挑战失败也说"好的挑战"；赛后私下问"今天怎么样？" | [IWAMASA] |
| **看见过程中的努力** | 不只看做没做到；让孩子觉得挑战失败也"没关系" | [JFA-SG]（原则 1） |
| **给孩子表达的时间** | 每次训练留时间听孩子的意见、担忧和建议 | [FCB-CC] |
| **一次只讲 1–2 个重点** | 用具体的话和示范 | [JFA-PH]；"1–2 个"为【本队约定】 |

## 四、与家长合作

1. **家长不是敌人，是伙伴。** 教练有责任帮助家长理解怎样支持孩子 [UEFA-10]。
2. **赛季初开家长会**，讲解《队规》《家长守则》和本守则，确保家长理解教练对球员的期望 [FA-COACH] [RSO]。
3. **定期反馈孩子的发展**（结合《球商分析系统》报告），不在群里公开比较或排名 [RSO]；"不公开排名"见《球商分析系统工作手册》12.2 节。
4. **只用官方渠道沟通**，不在场边、不在赛后情绪激动时讨论上场安排【本队约定】。

## 五、持续学习

- **持证上岗并持续学习。** 好教练在学习、持续学习，言行一致，是孩子的榜样 [JFA-PH]；JFA 推动替补席人员持有 D 级以上执照 [JFA-SAFE]。
- **完成儿童保护基础培训** [FIFA-GS]。
- **每月一次教练组复盘**：结合比赛视频，检查本队是否给了孩子足够的决策空间，场边指令是否过多【本队约定】。

## 六、违反守则的处理

参照英格兰足总教练守则的处理方式 [FA-COACH]：

1. 与儿童保护负责人 / 俱乐部负责人面谈；
2. 由另一名教练跟队观察指导一段时间；
3. 参加指定的教育培训；
4. 暂停带队；
5. 严重违反（体罚、欺凌、儿童保护问题）立即停止带队，按俱乐部规定和法律处理。

## 七、教练签名
